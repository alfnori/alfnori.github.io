# PRODUCT.md

## What is this

Personal CV/portfolio website for Adolfo Luiz Noriller Leite da Silva, a Senior Software Engineer with 10+ years of experience. The site serves as a professional presence, showcasing experience, skills, projects, and contact information.

## Audience

- Recruiters and hiring managers in tech companies
- Potential clients for freelance/collaboration work
- Professional network contacts

## Core job

Convince the visitor that Adolfo is a highly capable, experienced senior engineer worth hiring or collaborating with. The CV must communicate technical depth, breadth of experience, and professionalism within seconds.

## Content

- Personal info (name, title, location, contact)
- Professional summary
- Work experience (7 positions, 2011–2026)
- Technical skills (7 categories)
- Projects (6 placeholder projects)
- Education (UFPR)
- Languages (Portuguese, English, Spanish)

## Constraints

- Must be a single-page static site (Astro + Tailwind)
- Must support dark/light mode
- Must be responsive
- Content is in Portuguese (pt-BR)
- Deployed to GitHub Pages (alfnori.github.io)
- Must include JSON-LD structured data for SEO
- Must include Open Graph / Twitter meta tags
- Must have PDF CV download link

## Tech stack

- Astro 7
- Tailwind CSS 4
- TypeScript
- No JavaScript frameworks (pure Astro components)
